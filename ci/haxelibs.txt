# on each line. .github/actions/haxelibs installs them from a cache keyed on
# this list, and asks the registry only for a version the cache does not

# keeps running while lib.haxe.org is down. RELEASING.md has more.

# cache. Dependencies are not followed: a library that needs another lists
# both here, so that every version stays exact.

# and the versions a local checkout is developed against.
